#  Keyfaces

Keyfaces is a fun interactive keyboard project where pressing different keys triggers **meme pictures, characters, voices, and sounds**. Built with Next.js, React, TypeScript, and Tailwind CSS, it’s a playful experiment combining keyboard interactions, audio, and visual effects into one entertaining experience.
